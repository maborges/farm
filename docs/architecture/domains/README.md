## Critério de Uso

- Cada catálogo descreve fronteiras, ownership, integrações, regras de negócio e roadmap do domínio.
- Quando houver conflito entre catálogo, data model e norma, a norma imutável prevalece.
- Quando houver conflito entre catálogo e código, o código deve ser tratado como evidência primária, e a documentação deve ser atualizada por governança.
